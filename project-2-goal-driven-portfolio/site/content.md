## Projects Section

### CRM Digital FTE Factory
A multi-agent system where different AI agents perform distinct business roles — CRM operations, ticket handling, customer support, knowledge base lookup. Built with OpenAI Agents SDK and MCP integration, the system orchestrates multiple agents with escalation rules so work flows between them like it would between human team members. Backend runs on FastAPI and SQLModel. This was a learning project built during Agent Factory training, not a commercial deployment, but it demonstrates how agent orchestration works when you need more than one AI doing more than one job.

### Hackathon II: The Evolution of Todo
A Todo app that started basic and evolved into a cloud-native system with AI chat functionality. Built with Next.js 16, App Router, FastAPI backend, and Neon Serverless PostgreSQL with SQLModel ORM. The project was about taking something familiar and pushing it toward what AI-native architecture looks like — not bolting a chatbot onto the side, but rethinking what the app could do when an agent has access to your task data and can reason about it.

### Loop Engineering Practice
Built and tested agent workflows where an AI agent receives a task, evaluates what's needed, makes decisions, uses tools including Email MCP, and runs the loop — observe, reason, act, validate — until the task is complete. This project was practice in making agents that don't stop after one response. It's the pattern that makes Digital FTE systems possible: an agent checks if the work is done, and if not, it goes again.
