About

I'm transitioning into Agentic AI Engineering, building systems where AI agents do actual business work instead of just answering questions. I combine full-stack development skills with hands-on experience running a clothing and fashion business — I know what it's like to manage customer conversations on WhatsApp at midnight, to photograph products that need to sell, to handle the operational load that small businesses carry.

That context shapes how I think about automation: agents need to solve real problems for people who don't have engineering teams. My focus is on Digital FTE systems where agents take on complete business roles, running decision loops until work is finished, not just generating a response and stopping.

03 Act

Projects

EXECUTION // 01

CRM Digital FTE Factory

A multi-agent system where different AI agents perform distinct business roles — CRM operations, ticket handling, customer support, knowledge base lookup. Built with OpenAI Agents SDK and MCP integration, the system orchestrates multiple agents with escalation rules so work flows between them like it would between human team members. Backend runs on FastAPI and SQLModel. This was a learning project built during Agent Factory training, not a commercial deployment, but it demonstrates how agent orchestration works when you need more than one AI doing more than one job.

EXECUTION // 02

Hackathon II: The Evolution of Task App

A task app that started basic and evolved into a cloud-native system with AI chat functionality. Built with Next.js 16, App Router, FastAPI backend, and Neon Serverless PostgreSQL with SQLModel ORM. The project was about taking something familiar and pushing it toward what AI-native architecture looks like — not bolting a chatbot onto the side, but rethinking what the app could do when an agent has access to your task data and can reason about it.

EXECUTION // 03

Loop Engineering Practice

Built and tested agent workflows where an AI agent receives a task, evaluates what's needed, makes decisions, uses tools including Email MCP, and runs the loop — observe, reason, act, validate — until the task is complete. This project was practice in making agents that don't stop after one response. It's the pattern that makes Digital FTE systems possible: an agent checks if the work is done, and if not, it goes again.
