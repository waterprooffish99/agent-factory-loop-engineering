## hero
<h1>Salman Hassan</h1>
<p>I build autonomous AI systems that run loops — agents that plan, execute, verify, and iterate without a human in the loop.</p>

## about
<p>I started with web stacks — React, Next.js, FastAPI — but the problems I kept returning to weren't about rendering pages. They were about <strong>work that repeats</strong>: the research sweep you redo every Monday, the CRM update that never happens, the spec that drifts from the code.</p>

<p>So I moved up a layer. Now I build <strong>agentic workflows</strong> using the OpenAI Agents SDK, Model Context Protocol, and Spec-Driven Development. The loop is the pattern: declare the objective, spin up the phases, verify each output against its contract, and only stop when the checker says 20/20. My portfolio <em>is</em> one of those loops — you're reading the render phase right now.</p>

<p>When I'm not wiring agents, I'm writing the spec that the next agent will follow.</p>

## projects
### Aura Agentic Engine
<p><strong>What it does:</strong> An agentic engine that decomposes a high-level objective into a phased plan, executes each phase with specialised sub-agents, and verifies outputs against declared contracts before passing context forward.</p>
<p><strong>My role:</strong> Designed the phase contract schema, built the planner that turns objectives into ordered phases, and implemented the verifier that checks each phase's output before the loop continues.</p>

### Paper Watch AI
<p><strong>What it does:</strong> Monitors research sources (arXiv, conference proceedings, GitHub) for papers matching a declared interest profile, extracts the contribution claim and method, and surfaces only the ones that advance the user's stated question — not just keyword matches.</p>
<p><strong>My role:</strong> Built the retrieval pipeline with semantic filtering, designed the interest-profile schema, and wrote the summariser that outputs a one-paragraph "why this matters" for each hit.</p>

### Sentinel RAG Hub
<p><strong>What it does:</strong> A retrieval-augmented generation system that connects LLM responses to live external knowledge — API docs, internal wikis, codebases — so answers cite sources and stay grounded when the underlying data changes.</p>
<p><strong>My role:</strong> Architected the retrieval router (vector + keyword + graph), implemented the citation enforcer that rejects uncited claims, and built the refresh loop that re-indexes on schedule or on webhook.</p>

### Forge Automation Suite
<p><strong>What it does:</strong> A collection of agent workflows that automate repetitive knowledge work: PR description generation from diffs, spec-to-test scaffolding, dependency update impact analysis, and release note synthesis from commit history.</p>
<p><strong>My role:</strong> Defined the workflow DSL, built the GitHub Actions integration layer, and wrote the prompt templates that make each workflow produce review-ready output on first run.</p>

### Digital FTE / CRM Agent
<p><strong>What it does:</strong> An AI agent that operates a CRM like a human FTE would — it reads inbound emails, extracts action items, updates deal stages, drafts follow-ups, and flags stalled opportunities, all driven by a Spec-Driven Development contract that defines what "done" looks like for each task.</p>
<p><strong>My role:</strong> Authored the spec (objectives → phases → verifiers), built the email→action extractor using function calling, and implemented the CRM write-back with idempotency guards.</p>
